# 📧 Naive Bayes Email Detection

A simple implementation of a **Naive Bayes classifier** to detect emails as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) techniques.

---

## 🚀 Features

- Preprocessing of email text (cleaning, stopwords removal, etc.)
- Feature extraction using `TfidfVectorizer` or `CountVectorizer`
- Naive Bayes model training (`MultinomialNB`)
- Evaluation metrics: Accuracy, Precision, Recall, F1-score
- Inference on custom email text
